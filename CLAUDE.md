# Claude Code Instructions

Before working on this repository, read and follow [`AGENTS.md`](./AGENTS.md). It is the single source of truth for project-wide AI coding instructions.

Also read the relevant sections of:

- [`docs/engineering-standards.md`](./docs/engineering-standards.md)
- [`docs/code-style.md`](./docs/code-style.md)

Inspect the existing code before proposing or making changes. Follow established project patterns unless they conflict with `AGENTS.md` or the task explicitly requires a change.

Do not redesign architecture, introduce major dependencies, change public contracts, or create commits/releases unless explicitly authorized by the user.

When finishing a task, report the files changed, important decisions, tests and checks actually run, and any remaining limitations.
